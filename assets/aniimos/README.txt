# Aniimo art

Card art lives here, 256x256 WebP with a transparent background. The file
name matches the `id` in `../aniimos.json`:

```
assets/aniimos/gachapus.webp
assets/aniimos/scorchhowl.webp
```

Extra forms use `<id>-<form>.webp` and are listed under `forms` in the
manifest:

```
assets/aniimos/scorchhowl-prismana.webp
assets/aniimos/scorchhowl-highland.webp
```

- Crawled from the official wiki, trimmed and fitted into a square canvas.
- No image? No problem: the app falls back to a coloured tile with initials.
- File names must match the `id` **exactly** (case-sensitive on Linux/GitHub Pages).
