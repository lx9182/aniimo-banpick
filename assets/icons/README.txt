Element icons
=============

The 9 official element icons live here, 64x64 WebP (white glyph on the
official coloured disc). They are used in the pool cards and in the
element filter chips:

  light.webp      fire.webp       ice.webp
  dark.webp       lightning.webp  grass.webp
  water.webp      rock.webp       wind.webp

Sliced from the official wiki attribute sprite. If a file is missing the
app shows a coloured circle with the element's first letter, so the site
works fine without any icons.
